# Tresse GUI

Folders versioned and synchronized with
[Tresse](https://gitlab.com/ragusseven/tresse): pick folders — an existing
Tresse repository or a new one — connect them to a Tresse server or your own
S3 bucket, and sync.

Built with GPUI Kit and the `gpui-adaptive` design system, the same stack as
Money Manager, and shipped for Linux (flatpak and tarball), Windows, macOS and
Android.

## Status

Early: the application is being built stage by stage. The plan, the decisions
behind it and what is left live in the project's task card.
